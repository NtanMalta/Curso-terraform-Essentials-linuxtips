# 🚀 Terraform Essentials - LinuxTips

Este repositório contém meus estudos, anotações e laboratórios práticos desenvolvidos durante o curso gratuito **Terraform Essentials** oferecido pela [LinuxTips](https://www.linuxtips.io/).

O objetivo principal deste projeto é construir uma base sólida sobre a utilização do Terraform e entender na prática como provisionar e gerenciar Infraestrutura como Código (IaC).

## 📚 O que estou aprendendo / construindo

Ao longo dos módulos e dos testes salvos aqui, o foco está em:

* **Fundamentos de IaC:** Entender como o Terraform funciona, sua arquitetura e em quais cenários ele deve ser utilizado.
* **Comandos Essenciais do Dia a Dia:**
  * `terraform init`: Inicialização do diretório de trabalho e download de *providers*.
  * `terraform plan`: Visualização prévia das modificações na infraestrutura.
  * `terraform apply`: Execução e provisionamento real dos recursos.
